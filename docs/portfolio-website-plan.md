# Portfolio website plan (draft)

Anastasiya M. · UI/UX designer, Human–AI interaction · for a Master's application in South Korea

## 1.Positioning

I design AI-assisted interfaces, turning AI features into screens built around the person using them.Audience: the admissions committee of a Master's degree program in South Korea. The site's job is to present each case. Everything about me personally is in the application documents.

## 2.Pages

- ### Home

  One page with the hero, the four projects and the contact. In a few seconds it shows that my focus is AI in interface design and leads into the cases.
- ### Case page (one per project)

  Miri, RentFlow, Studio, SeMA. Each case is shown from the first question to the final screens, with the reasoning in between.

## 3.Home page blocks

1. 1

   ### Hero

   Name and surname, links to Projects and Contact, the headline "I design AI-assisted interfaces", two short lines below it, and "UI/UX designer · Human–AI interaction" with four dots in the project colors. **What it says:** what I design and that AI is the focus.
2. 2

   ### Projects

   Four case blocks in a fixed order, with a side rail to jump between them. Each block has a number, format, status and year, the name, a Question and a Decision, topic tags and a screenshot. The screenshot size follows the project's format: a tall mobile screen, a wide dashboard, a full web page. **What it says:** the first three cases build the AI anchor, and the fourth shows UX audit and redesign skills.
   - **01 Miri, AI concierge.** Mobile app · Concept · 2026. Solo, self-initiated. How should the concierge get to know a guest who doesn't want to be asked questions?
   - **02 RentFlow, property management platform.** Web app · Concept · 2026. Team project, so the case page will say who did what. How should AI speak to an owner, a tenant and a manager about the same property?
   - **03 Studio, AI concept boards.** Web app · In progress · 2026. Solo, self-initiated. It has a placeholder for now and will be finished before the site launches. How can a designer use AI to assemble a concept board and still feel that every choice is theirs?
   - **04 SeMA, Seoul Museum of Art website redesign.** Web redesign · Concept · 2026. Solo, self-initiated. What happens when the findings of a UX audit are applied to an existing museum website?
3. 3

   ### Contact

   A large email address, my name and a "Back to top" button. **What it says:** one clear way to reach me.

## 4.Questions to me

1. Who is the site for?

   **My answer:** my application to a Master's degree program in South Korea. The focus is on presenting each case.
2. Which pages does the site need?

   **My answer:** the home page as it is now, plus a separate page for each project. No About page and no CV, because the application documents contain all the information about me.
3. In what order are the projects shown, and why?

   **My answer:** Miri, RentFlow, Studio, SeMA. The order shows my AI anchor in design. Later I might swap RentFlow and Studio.
4. Will Studio be ready?

   **My answer:** it is in progress, so for now it has a placeholder. It will be finished by the time the site is final, and then all four projects will be complete.
5. What was your role in each project?

   **My answer:** RentFlow is a team project, and I will describe that on its case page. On Miri, Studio and SeMA I was the only designer. All four are self-initiated, with no real client.
6. Did you test the designs with real users?

   **My answer:** no, none of the four were tested with real users. Each case page will cover the details.
7. Do you have testimonials, or work under NDA?

   **My answer:** no testimonials, so there is no testimonials block. Nothing is under NDA, so all four cases are shown.
8. How should people contact you?

   **My answer:** email only.
9. Why are the screenshots different sizes?

   **My answer:** each project is a different format (mobile, dashboard, web page), so the image adapts to the case. The current images are temporary, and I will provide high-quality ones for each project.
10. Which language should the site be in?

    **My answer:** English only.
11. Should all four case pages follow the same structure, and which sections should it have?

    **Later:** I will decide this when I work on each case page.
